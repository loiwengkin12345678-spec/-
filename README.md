第一階段：聖經起源（創世紀至舊約）

📖 階段主題金句： 「起初天主創造了天地。」（創 1:1）

出處： 《聖經·創世紀》1:1-31

金句： 「天主看了祂所造的一切，認為很好。」（創 1:31）

約 BC 4000 年後：原罪與救恩許諾

出處： 《聖經·創世紀》3:15

金句： 「我要把仇恨放在你和女人中間，你的後裔和她的後裔中間；她的後裔要踏碎你的頭，你要牽制祂的腳跟。」（創 3:15）

約 BC 2500 年：諾厄方舟與彩虹之約

出處： 《聖經·創世紀》9:12-17

金句： 「我把我的虹霓放在雲霧中，作我與大地立約的記號。」（創 9:13）

約 BC 2000 年：天主召叫亞巴郎並立約

出處： 《聖經·創世紀》12:1-3；17:4-8

金句： 「離開你的故鄉、你的親族和你的父家，往我所要指給你的地方去。」（創 12:1）

約 BC 1900 年：厄撒格與雅各伯承傳盟約

出處： 《聖經·創世紀》26:3-5；28:13-15

金句： 「地上萬民都要因你的後裔獲祝福，因為你聽從了我的話。」（創 26:4）

約 BC 1800 年：若瑟被賣入埃及後成為宰相

出處： 《聖經·創世紀》37:28；41:39-41

金句： 「天主派遣我在你們以先來，是為給你們在地上保留後裔。」（創 45:7）

約 BC 1700 - 1300 年：以色列人喺埃及流落受奴役

出處： 《聖經·出埃及記》1:8-14

約 BC 1290 年：梅瑟蒙召（燃燒的荊棘）

出處： 《聖經·出埃及記》12:11-14；14:21-31

金句： 「這血在你們所住的房屋上要當作你們的記號；我一見這血，就逾越你們。」（出 12:13）

約 BC 1250 年：西乃山立約與頒布十誡

出處： 《聖經·出埃及記》20:1-17

金句： 「我是上主你的天主，曾領你出了埃及地奴隸之所。除我之外，你不可有其他的神。」（出 20:2-3）

約 BC 1250 - 1210 年：曠野漂流四十年與賜予瑪納

金句： 「人生活不只靠麵包，也靠上主口中所發的一切言語。」（申 8:3）

約 BC 1200 - 1050 年：民長時代

出處： 《聖經·民長紀》2:16-19

金句： 「那時以色列中沒有君王，各人任意而行。」（民 21:25）

約 BC 1030 年：先知撒慕爾傅油撒烏耳為首任君王

出處： 《聖經·撒慕爾紀上》10:1

約 BC 1000 年：達味統一以色列並定都耶路撒冷

出處： 《聖經·撒慕爾紀下》5:1-10

金句： 「上主是我的牧者，我實在一無所缺。」（詩 / 詠 23:1）

約 BC 960 年：所羅門王建成第一座聖殿

出處： 《聖經·列王紀上》6:1-38

金句： 「敬畏上主是智慧的開端。」（箴 9:10）

出處： 《聖經·列王紀上》12:16-20

金句： 「我們在達味內有什麼分？我們喺耶塞的兒子內有什麼業產？」（列上 12:16）

約 BC 750 年起：先知依撒意亞預言默西亞將由童貞女所生

出處： 《聖經·依撒意亞》7:14

金句： 「看，有位童貞女要懷孕生子，人將給祂起名叫厄瑪奴耳。」（依 7:14）

BC 722 年：北國以色列亡於亞述帝國

出處： 《聖經·列王紀下》17:5-6

金句： 「以色列人遭遇這事，是因他們得罪了領他們出埃及地的上主他們的天主。」（列下 17:7）

BC 586 年：南國猶大亡於巴比倫，聖殿被毀

出處： 《聖經·列王紀下》25:1-12

金句： 「當我們坐在巴比倫河畔，追億起錫安，不禁淚流滿面。」（詩 / 詠 137:1）
